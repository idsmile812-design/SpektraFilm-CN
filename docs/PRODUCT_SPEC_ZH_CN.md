# 光谱胶片：中文版产品与实施规范

## 产品目标

基于 Spektrafilm for Android v0.10.0，提供自然、完整、易用的简体中文体验。照片解码、胶片模拟和导出全部在手机本地完成，无账号、无照片上传、无 App 内联网。普通用户无需理解光谱模型，也能完成“导入 → 选风格 → 微调 → 保存”。

上游基线：tag `v0.10.0`，commit `d7f9fcf86213c9dc46d2a2b5ddfa41dc8040ef0e`。

## 不可突破的边界

- 不修改 `engine/spektra-core/src/main/cpp/**`，不改变光谱引擎、数值精度、随机模型或渲染结果。
- 保留现有 application ID、JNI 包名、ABI、原生模块和生命周期/缓存/导出协调机制。
- 不升级 AGP、SDK、NDK；新增相机依赖使用固定 CameraX 稳定版并保留严格依赖锁，不替换既有依赖，不做无关重构。
- 本阶段支持应用内静态拍照；不做视频、相机固件、应用商店发布或生产签名。
- 所有新增代码沿用现有 Kotlin、Compose、资源和测试结构。
- 保留 GPL-3.0 义务、上游归属和 `Film modeling powered by spektrafilm` 声明。

## 中文本地化

- 工作显示名为“光谱胶片”；关于页保留 Spektrafilm 和 Spektrafilm for Android 原名。
- 简体中文系统默认中文，其他系统默认英文；设置提供“跟随系统 / 简体中文 / English”。
- 为所有用户可见字符串提供 `values-zh-rCN` 资源，包括编辑器、工具、错误、通知、诊断、设置、帮助和关于页，而非只翻译首页。
- 胶片官方型号保留原文，例如 `Kodak Portra 400`；中文用于分类、特性、用途和帮助，不虚构官方中文型号。
- 推荐术语：胶片、相纸、颗粒、光晕、曝光、白平衡、LUT、原图对比、专业调整、保存到相册。
- 保留字符串占位符、格式参数、链接、`translatable="false"` 内容和必要英文署名；翻译不得改变参数含义。
- 中文帮助、术语说明和隐私说明随 App 本地提供。

## 视觉与交互约定（专业暗房）

- 整体是照片优先的暗房工具，不是换色的 Material 样板：近黑与暖灰表面、暖白正文、单一琥珀操作色。禁止紫色/蓝色 AI 渐变、漂移彩虹背景、连续描边卡片、满屏胶囊和装饰性大标题。
- 暗色为默认交付观感：background `#141311`、surface `#1B1A18`、surfaceVariant `#292621`、primary `#D8A75D`、onPrimary `#261A08`、onBackground/onSurface `#F2EEE7`、onSurfaceVariant `#C8BFB4`、outline `#665E54`。浅色同族：background `#FAF7F1`、surface `#FFFDF8`、surfaceVariant `#EEE8DE`、primary `#795316`、onSurface `#211E1A`、onSurfaceVariant `#625B52`、outline `#8B8073`。可微调对比度，但保持暖灰同族和单琥珀色。
- `SpektraBrand.canvasNearBlack`、`canvasCurve`、`canvasMagnifier` 等中性照片画布不随主题变色；它们用于判断照片，不属于界面配色。
- 字体使用系统 Default 字体（中文不缺字、离线可用），以 Medium / SemiBold / Bold 和合理字号、行高、字距形成层级；大标题保持克制，不做英文海报式挤压。正文不全用等宽字体；只有实时数值读数启用 tabular nums。
- 圆角分层：小组件 8–12dp，分组面板约 14–16dp，底部弹层/对话框可更大；不要所有元素统一 20dp 胶囊。
- 保留 `MotionScheme.expressive()` 的主题级动效，但欢迎页等静态页面不使用无限循环、漂移或装饰性动画。
- 设置分组使用低层级暖灰表面与分隔，始终展开的分组不得伪装成可点击折叠卡；生效时机说明（下次启动、返回编辑器等）紧邻对应分组。
- 动态取色（Material You，Android 12+）默认关闭；若本地已存明确选择则原样尊重，不迁移、不删除 key。系统/浅色/深色三种主题模式保留。
- 选中状态不能只靠颜色：标签页同时使用字重和短下划线，并保留选择语义。主要触控目标至少 48dp。

## 核心用户流程

### 导入

- 使用系统照片/文件选择器，支持现有 JPEG、HEIC、RAW、DNG 路径。
- 清楚区分普通照片和 RAW，但不向普通用户暴露解码细节。
- 保留内置示例图，便于首次体验。
- “打开”同时提供拍摄照片、相册选择和文件选择。拍照使用 CameraX 应用内取景，相机权限由用户主动授予；拍后可重拍或确认，确认后走同一 `content://` 导入、EXIF 方向、会话与导出链。
- 拍摄原图只写应用私有 `cacheDir/captures/`，通过 non-exported FileProvider 暴露该唯一子目录，不自动写公共相册、不覆盖原图；取消与重拍删除未采用文件，采用后保留以支持恢复与导出。
- 无相机、拒绝权限、权限撤销、拍照失败和缓存被清理都有中文恢复路径；导出忙碌时禁止拍摄换源，相机/确认页有独立返回与模态语义。真机需验证鸿蒙取景、方向、前后台、权限和恢复，不能用 JVM 测试代替。

### 选择风格

- 首屏优先展示现有预设，而非要求用户分别理解胶片和相纸。
- 星标入口“风格”直接打开内置预设列表，不再先要求用户在“来源 / 预设”之间二选一；点“完成”直接打开色调曲线。
- 内置预设点选即应用，行内展示名称、胶片/相纸配置和说明，并标明当前已应用项；不再使用“先下拉选择、再点应用”的两步操作。
- “风格”打开独立模态图鉴页，提供当前照片预览、真实规格、已核实的原版包装/胶卷素材与全部内置风格；无已核实图片时使用明确标注的信息卡，不伪造原版包装。自定义预设入口保留。图鉴显示时屏蔽底层编辑器语义，返回键先关闭图鉴；许可、作者、来源、年份与修改说明可在关于页离线查看。
- 内置预设按“仅一遍”语义工作：同一轮浏览中切换风格会替换上一款，不叠加；手动调整后显示“已应用 · 已调整”，不得把修改后的画面冒充为原始配方。换源、重置、导入或粘贴后清除旧归属。
- 预设目录加载中显示真实加载状态；目录已就绪但内置资源为空时明确提示“内置风格读取失败”，不得谎称没有预设；只有自定义预设为空时才显示空目录引导。
- 胶片/相纸自由组合放入“自定义”或“专业调整”。
- 保留现有 StockBrowser 的型号、ISO、分类和特性卡片，补齐中文说明。

### 微调

- 首层只突出效果强度、曝光、颗粒、光晕等高频控制。
- 提供原图对比、撤销和重做。
- 曲线、局部蒙版、扫描仪和输出色彩空间等保留在“专业调整”，不得删除功能。
- 五阶段与参数组始终显示中文/英文文字；参数组使用可横向滚动的文字标签，保留已修改圆点、`Role.Tab` 和选中语义，触控热区至少 48dp，不依赖长按提示才能理解。
- 新控件必须接回现有 EditorSession / ParamsState / 导出协调器，不能建立只改变 UI 的平行状态。
- 应用预设、保存预设、导入/导出结果、复制/粘贴结果统一通过 Snackbar 反馈，不因当前面板不同而丢失反馈；不得为同一错误叠加重复 Toast。

### 导出

- 导出选项全部位于本次导出面板（ExportSheet）：格式、质量、尺寸、色彩空间、文件名和位置。全局设置只提供这些选项的默认值，不会替代面板中的本次选择。
- 默认 JPEG、sRGB、合理原始分辨率和高质量；高级格式保留在专业设置。
- 主操作为“保存到相册”，顶栏使用带文字的主按钮，不混在无标签图标中；窄屏时设置与关于收进溢出菜单，关键操作在大字体下不得截断。
- 自定义长边使用与 `ExportOptions` 一致的范围 256–16384 px：留空表示原始尺寸，不放大；非数字、小数、带单位文本或超出范围时在输入框下就地提示并禁用导出，不做静默截断。16 位 TIFF/PNG 始终按全分辨率导出，不受该字段影响。
- 导出文件名支持 Unicode：中文、重音字母、空格、下划线和连字符保留；路径分隔符、emoji 及其他不需要的标点移除。面板用与导出完全相同的清洗函数预览“带后缀的实际文件名”；清洗后为空时提示并自动使用 `Spektrafilm_<时间戳>`，任何情况下都不会导出空名或带路径的文件名。
- 不覆盖原图，不覆盖已有导出。
- 成功后提供“查看”“分享”“继续编辑”。
- 失败时显示中文原因和可执行的恢复建议，错误码只能作为附加诊断信息。
- 渲染期间显示真实状态和取消按钮；没有实测依据时不承诺固定秒数；统一 Snackbar 不覆盖或破坏导出全屏状态。

## 引导、布局与可访问性

- 首次引导为单页、左对齐的照片工具导览：窄幅静态光谱标识、品牌名、短价值说明、编号三步“导入照片 / 选择风格 / 微调并保存”、本地隐私说明和“开始编辑”主按钮；指南、设置、问题反馈与 GPL/上游署名入口保留。后续启动恢复上次工作状态。
- 引导页和编辑器教练层是 Compose 覆盖层而非系统 Dialog：显示时用 `clearAndSetSemantics` 屏蔽底层编辑器的无障碍节点，同时保留覆盖层自身的按钮和可点击背景。两者分别以 welcome 标题和“快速提示”作为 `paneTitle`，让 TalkBack 进入时能说出当前是哪一层。
- 教练层内容可纵向滚动，“知道了”按钮高度至少 48dp，短屏或 200% 字体下仍可到达；遮罩点击关闭与按钮各自保留独立语义，不合并成一个节点。
- 使用指南的分区是低层级 14dp 分组（面板级圆角），不把每条细节做成 20dp 通用卡片；阶段与参数组使用常驻文字标签，不依赖长按提示。
- 主要触控目标至少 48dp。
- 中文文本在窄屏和 200% 字体下不得截断关键操作。
- 图标按钮具有中文 contentDescription；选择状态不能只靠颜色表达。
- 根返回顺序固定为：先关闭 100% 放大镜，再处理隐藏工具栏、裁剪/蒙版/取样工具、面板与页面；诊断页系统返回到设置，使用指南系统返回到关于。
- 保持旋转、进程恢复和后台导出的现有行为。

## 本地与隐私

- 本中文版是完全本地处理版本：飞行模式下必须能完成导入、全部胶片计算和导出。
- App 核心不发起任何 HTTP 请求；主 Manifest 不声明 `INTERNET`，不含更新检查、账号、统计、广告、API key 或照片上传路径。
- 不增加账号、统计、广告、云处理或新的网络依赖。
- 不提供 App 内更新检查或更新对话框。GitHub、源代码、许可证等外部链接仅在用户主动点击后通过系统 `ACTION_VIEW` 交给浏览器打开；App 不读取网页内容，链接附近保留“将在浏览器打开”的准确语义。
- 默认移除导出照片的 GPS；诊断信息不包含照片内容或不必要的完整路径/元数据。诊断复制/分享和对导出照片的查看/分享仍由用户主动触发。

## 测试与验收

每次相关修改至少运行聚焦测试，阶段完成时运行：

```bash
./gradlew :app:testDebugUnitTest :app:lint :app:assembleDebug
tools/parity/run_engine_parity.sh /tmp/spektrafilm-cn-parity-o2
SPK_PARITY_EXTRA_FLAGS="-O3 -ffast-math -fno-finite-math-only" \
  tools/parity/run_engine_parity.sh /tmp/spektrafilm-cn-parity-ship
```

资源修改需检查缺失/重复 key、占位符和格式化参数。UI 修改需沿用现有测试体系覆盖导入、预设、调参、取消、恢复和导出，不引入新测试框架。

最终在真实 Android 手机完成：中文首次启动、JPEG 导入、选择预设、强度调整、原图对比、取消与重新渲染、保存到相册、查看/分享、退出恢复、飞行模式离线导出，以及一个受支持的 RAW/DNG 样本。记录设备、Android 版本和实际耗时。只有这条真实流程走通，才算手机端完成。
